FOLDER ASSETS
--------------

Letakkan file grafis dan suara Anda di folder ini.
Gunakan format berikut untuk kemudahan integrasi:

/characters/
  - raka.png (200x400)
  - adrian.png (200x400)
  - bella.png (200x400)

/backgrounds/
  - magang.png (1280x720)
  - desktop.png (1280x720)

/ui/
  - button_normal.png (200x60)
  - button_hover.png (200x60)
  - button_click.png (200x60)
  - icon_evidence.png (64x64)

/audio/
  - click.mp3
  - notify.mp3
  - bgm_main.mp3

Pastikan untuk memperbarui path di PreloadScene.js setelah menambahkan file asli.
